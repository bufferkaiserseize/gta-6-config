## 🧩 About

**GTA 6 Config** is a comprehensive configuration utility for GTA 6 on Windows PC, offering graphics tweaks, performance optimization, control remapping, and script extender support.

Based on popular tools like **GTA V Config**, **OpenIV**, and **Script Hook V**.

---

## ✨ Features

### 🎮 Graphics Tweaks
- Resolution Scaling — adjust internal render resolution
- Texture Quality — fine-tune texture detail levels
- Shadow & Reflection — customize shadow and reflection quality
- Anti-Aliasing — select MSAA, FXAA, or TAA

### ⚡ Performance Optimizer
- FPS Boost — disable heavy effects for higher frame rates
- Memory Management — optimize RAM and VRAM usage
- CPU Priority — set process priority for smoother gameplay
- Background Processes — suspend unnecessary tasks

### 🕹️ Control Remapper
- Key Binding — reassign keyboard and mouse controls
- Controller Support — configure gamepad mappings
- Sensitivity Settings — adjust mouse and aim sensitivity
- Macro Support — create and assign macros

### 📜 Script Extender
- Lua Scripting — run custom Lua scripts for extended functionality
- Mod Loader — load and manage mods seamlessly
- Plugin Support — integrate community plugins
- Debug Console — access advanced debugging tools
